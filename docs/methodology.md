# 方法总览

## 1. 项目定位

本项目是静态数据快照下的探索性研究，包含：

1. SQL 清洗和企业实体去重；
2. 三池画像与资质嵌套诊断；
3. 方向 1：资质叠加的分层匹配；
4. 方向 2：高企内部可解释模型；
5. 资质叠加潜力评分原型。

## 2. 数据流

```text
Excel → SQLite raw tables → SQL 标准化/UNION/去重
      → merged_clean → enterprise_master → high_tech_cohort
      → high_tech_analysis（SQL 分组、资本四分位、建模字段）
      → 方向 1 匹配 → 方向 2 模型 → 评分模型
      → 聚合表 / 图表 / 报告
```

## 3. 分析单元

- `merged_clean`：资质×企业成员记录，用于池间画像。
- `enterprise_master`：一个信用代码一行，用于跨池标记和资质组合。
- `high_tech_cohort`：只保留高企，共 29,323 家；方向 1、2 的共同母体。
- `high_tech_analysis`：在 SQL 中补齐高频行业/区县/企业类型分组和资本四分位，供方向 1、2 共用。

## 4. SQL 与 Python 分工

- SQL：导入表、状态过滤、窗口去重、跨池检测、派生字段、分层聚合、资质组合构建、分析数据集和特征分组。
- Python：四分位数、匹配、Bootstrap、逻辑回归、校准、图表和报告生成。

## 5. 时间口径

分析日为 2026-10-17。数据最新成立日期为 2022-12-30，最新核准日期为 2023-05-05。年龄按分析日计算，因此结果反映的是静态快照下的年龄，不代表当前政策状态。

## 6. 为什么不做独立组显著性检验

三池高度嵌套，特别是小巨人 99.73% 同时为高企。独立样本假设不成立。方向 1 采用匹配和效应量描述，方向 2 采用高企内部模型，避免把嵌套结构误当作三个独立总体。
